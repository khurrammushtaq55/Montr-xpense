# Montr-Xpense

## 📌 Overview
Montr-Xpense is an intuitive expense tracking Android application built using **Kotlin**, **MVVM architecture**, and **Room Database**. It helps users efficiently manage their daily expenses with a simple and user-friendly interface.

## 🚀 Features
- **Expense tracking** with category-based management
- **Room Database** for offline storage
- **MVVM architecture** for better code separation
- **Kotlin Coroutines** for efficient background operations
- **LiveData & ViewModel** for UI updates
- **Simple and interactive UI**

## 🛠️ Technologies Used
- **Kotlin** - Programming language
- **Room Database** - Local storage
- **MVVM Architecture** - Organized code structure
- **Kotlin Coroutines** - Background task management
- **LiveData & ViewModel** - UI responsiveness
- **Material Design Components** - Modern UI elements

## 📥 Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/khurrammushtaq55/Montr-xpense.git
   ```
2. Open the project in **Android Studio**.
3. Build and run the project on an emulator or a physical device.

## 📖 Usage
1. **Add new expenses** by entering the amount and category.
2. **View stored expenses** with an intuitive UI.
3. **Delete or modify expenses** as needed.

## 💡 Best Practices Implemented
- **Separation of concerns** - Clear distinction between UI, data, and logic layers.
- **Dependency Injection** - Efficient dependency management.
- **Lifecycle-aware components** - Ensures smooth performance and avoids memory leaks.
